Project story

Designing an editorial piece around Mustafa's album, Dunya

This magazine was designed to visually support the tone of Mustafa's new album, Dunya. I built the layouts in InDesign with a quieter editorial rhythm so the photography, typography, and pacing could carry the emotional weight of the story.

The focus was on giving each page room to breathe while keeping the spreads cohesive. That meant balancing strong imagery with restrained text placement and using layout shifts carefully so the sequence still felt unified from page to page.

Deliverables

What was designed

  • Magazine page and spread layouts built in Adobe InDesign
  • Editorial pacing shaped around Mustafa's album, Dunya
  • Image-led compositions with restrained typography placement
  • Print-ready layout files prepared for presentation and review
Process

How the magazine came together

The layout direction was developed around mood, pacing, and how each image could support the feeling of the album without overcrowding the page.

01

Visual tone

I started by defining a quieter editorial tone that matched the atmosphere of Dunya, using space and restraint instead of overly busy page construction.

02

Layout building

Inside InDesign, I built the spreads around image hierarchy, alignment, and page flow so the magazine would feel intentional from one turn to the next.

03

Spread refinement

The final pass focused on cleaning typography, adjusting balance across the spreads, and making sure the sequence felt cohesive as a complete editorial piece.
