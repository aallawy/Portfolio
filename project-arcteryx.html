Project story

Designing a motion system that feels cinematic and reusable.

For this project I designed a branded stinger, a lower third system, and infocard MOGRTs in After Effects, then used them inside a final edit composed in Adobe Premiere Pro. The goal was to make the video feel like a trailer for the Arc'teryx Winter Film Tour while still keeping the motion package clean, structured, and usable beyond one single video.

This version was built for the 2026 tour, but the motion graphics themselves were designed as templates with editable text so they can be carried forward and adapted every year. That balance between atmosphere and flexibility was the core of the project.

Deliverables

Motion package created

  • Branded intro stinger for strong opening momentum
  • Lower third system with editable title and role fields
  • Info-card MOGRT templates for reusable yearly updates
  • Final trailer-style edit assembled in Premiere Pro
  • Motion language built to feel sharp, minimal, and cinematic
Motion system

Three pieces built to work together on every tour edit.

The final video is only one part of the project. The real system sits underneath it: modular motion graphics that give the edit consistency while still staying easy to update in future versions.

01

Branded stinger

The opening sting was designed to set the tone fast, giving the piece a cold, dramatic entry point that feels closer to a film trailer than a basic title card.

02

Lower third system

The lower thirds were built as a consistent on-screen language for names and locations, keeping the overlays clean and readable without overpowering the footage.

03

Info-card templates

The info cards were built as editable MOGRTs so dates, titles, and event details can be refreshed every year without rebuilding the system from scratch.
